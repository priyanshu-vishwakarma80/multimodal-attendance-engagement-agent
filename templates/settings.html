Privacy Assurance

The Multimodal Attendance & Engagement Agent is designed with a privacy-first, edge-compatible architecture:

  • Face detection runs strictly in-memory on local frames using CPU-efficient OpenCV cascades.
  • Raw biometric images are never persisted to external cloud endpoints.
  • Audio processing evaluates only statistical RMS/dB and zero-crossing frequencies to determine interaction levels, without transcribing or storing private conversation recordings.
  • Local SQLite database stores metadata and telemetry securely on the host device.
